# Changelog

## Changes since v0.2.0

### Features

- Rotated provider keys now apply on the next inference call of running capsules. No restart needed. ([#168](https://github.com/murmur-nexus/murmur/pull/168))
- Set token spend limits per session with `inference.max_session_tokens` and per machine per day with `spend.machine_tokens_per_day`. Calls that would exceed a limit are stopped before they reach the provider. ([#167](https://github.com/murmur-nexus/murmur/pull/167))
- `mur ps` lists running capsules and `mur stop @1` stops one, naming any commands or child capsules left behind. ([#164](https://github.com/murmur-nexus/murmur/pull/164))
- `mur run` and `mur doctor` warn when `capabilities.env.allow` grants a secret, and say whether the capsule actually receives it. `mur run --explain-scope` now rejects invalid lifecycle flag values. ([#165](https://github.com/murmur-nexus/murmur/pull/165))
- Tools can declare a write destination based on another input, or declare that they write nothing. W-SEC-018 now lists every undeclared property. ([#160](https://github.com/murmur-nexus/murmur/pull/160))
- Capsules with `capabilities.plan.submit` can submit a plan of steps. The runtime runs it in one call, with independent steps in parallel. ([#136](https://github.com/murmur-nexus/murmur/pull/136))
- `delegate-task` returns as soon as the child capsule starts. A capsule can delegate several tasks at once and gets each result later as a background task. This needs `task_acceptance: queue`, a large enough `queue_depth` and `after_task: sleep`. ([#135](https://github.com/murmur-nexus/murmur/pull/135))
- `mur trace show` and `mur trace steps` display plan runs: structure, step status, attempts, duration and outcome. ([#132](https://github.com/murmur-nexus/murmur/pull/132))
- Traces now link parent and child capsules in a delegation. `mur trace show` shows both sides, each outcome and the reason for any refusal. ([#125](https://github.com/murmur-nexus/murmur/pull/125))
- Installed artifacts record the interfaces they use. `mur list --contract murmur:hook` shows which artifacts a change to that interface would break. ([#119](https://github.com/murmur-nexus/murmur/pull/119))
- `mur run --explain-scope`, `mur doctor` and the trace show which directory each tool, driver and hook can reach. ([#118](https://github.com/murmur-nexus/murmur/pull/118))
- Capsules can mark workdir subpaths as `capabilities.filesystem.read_only`. Writes to them are refused and logged. ([#114](https://github.com/murmur-nexus/murmur/pull/114))
- Capsules with `capabilities.spawn.allow` can delegate tasks to child capsules through the built in `delegate-task` tool. No limits apply yet. ([#110](https://github.com/murmur-nexus/murmur/pull/110))
- `mur run --resume` tells the agent which background shell command was lost when the capsule was killed. ([#108](https://github.com/murmur-nexus/murmur/pull/108))
- A child capsule records how its session ended in `completion.json` and reports the result to its parent. An unreadable spawner handle fails with `E-RUN-020`. ([#107](https://github.com/murmur-nexus/murmur/pull/107))
- The trace records where each task came from and its trust level. Messages forwarded from untrusted tasks stay untrusted. ([#96](https://github.com/murmur-nexus/murmur/pull/96))
- `trace.retain` and `context.retain` limit how much session and conversation data is kept. New `mur conversation ls`, `rm` and `truncate` commands manage it. ([#91](https://github.com/murmur-nexus/murmur/pull/91))
- `mur run --resume @1` continues a previous conversation. Add `--resume-mode compact` when it no longer fits the context window. ([#90](https://github.com/murmur-nexus/murmur/pull/90))
- `mur trace show --body` prints exactly what each turn sent. `mur trace steps` shows the session tree. `mur trace diff` shows where two runs' prompts first differ. ([#89](https://github.com/murmur-nexus/murmur/pull/89))
- An `on-task-start` hook can return `seed-context` to preload memory into a task, within a budget set by `context.seed_budget`. ([#85](https://github.com/murmur-nexus/murmur/pull/85))
- Traces and OpenTelemetry spans record the provider's real token counts, including cache reads and writes. Compaction savings are now reported accurately. ([#80](https://github.com/murmur-nexus/murmur/pull/80))
- Artifacts can be configured with a `config:` block in the manifest. A bad block stops the launch. ([#79](https://github.com/murmur-nexus/murmur/pull/79))
- Artifacts can declare `capabilities.state` to get a durable store per capsule, kept outside the workdir. ([#75](https://github.com/murmur-nexus/murmur/pull/75))
- Capsules can share single files with peers over A2A using expiring handles. Knowing a path is not enough to read a file. ([#74](https://github.com/murmur-nexus/murmur/pull/74))
- `exports.files` lets external processes read part of the workdir over HTTP without an inference call. ([#73](https://github.com/murmur-nexus/murmur/pull/73))
- Hooks with `capabilities.task_io.read` can read a task's input and result at `on-task-end`, so they can validate output and reopen the task. ([#70](https://github.com/murmur-nexus/murmur/pull/70))

### Bug Fixes

- Agent capsules now shut down cleanly on `SIGTERM`. A second `SIGTERM` or a 20 second timeout forces exit. `mur stop` reports tasks whose ending was not recorded. ([#176](https://github.com/murmur-nexus/murmur/pull/176))
- `mur run` and `mur doctor` warn with `W-SEC-029` when a sealed capsule's compiler toolchain cannot be checked. ([#175](https://github.com/murmur-nexus/murmur/pull/175))
- Shell command results now include the program name. ([#161](https://github.com/murmur-nexus/murmur/pull/161))
- `mur doctor` no longer fails on unset manifest variables. It lists them instead. ([#158](https://github.com/murmur-nexus/murmur/pull/158))
- Responses cut off at `inference.max_tokens` are now marked as truncated instead of saved as a final answer. ([#153](https://github.com/murmur-nexus/murmur/pull/153))
- Linux x86_64 binaries now run on glibc 2.34 and newer. The installer fails clearly on older systems. ([#150](https://github.com/murmur-nexus/murmur/pull/150))
- `mur-roost` no longer needs provider API keys. Capsules missing from `--spawn-allow` are refused by name. ([#137](https://github.com/murmur-nexus/murmur/pull/137))
- `mur-roost` now installs with `mur`. `mur doctor` reports when it is missing or unreachable. ([#133](https://github.com/murmur-nexus/murmur/pull/133))
- `mur deploy` no longer sends the wrong platform binary for artifacts installed from a remote registry. ([#127](https://github.com/murmur-nexus/murmur/pull/127))
- Unknown manifest keys now trigger a warning that says whether it is a typo or a newer key. `--explain-scope` shows read only paths and whether they are enforced. ([#124](https://github.com/murmur-nexus/murmur/pull/124))
- Tools can mark inputs as file destinations, so read only checks no longer guess from key names. Unannotated tools warn with W-SEC-018. ([#122](https://github.com/murmur-nexus/murmur/pull/122))
- `mur eval` now checks each case against the current host state, not the state from the first case. ([#106](https://github.com/murmur-nexus/murmur/pull/106))
- Repeat runs send identical prompt prefixes, so provider prompt caching now works. ([#76](https://github.com/murmur-nexus/murmur/pull/76))
- `mur doctor`, `--explain-scope` and the trace show how the host allows user namespaces. Weak setups now warn. ([#72](https://github.com/murmur-nexus/murmur/pull/72))

### Other

- Breaking: `~/.murmur` is now private to its owner. Each account needs its own. `mur run` warns with `W-SEC-028` if a key sits in a readable config file. ([#170](https://github.com/murmur-nexus/murmur/pull/170))
- Breaking: `mur run` refuses capsules whose `env.allow` lists a variable the credential filter removes. Remove those entries. More secret names are now detected. ([#169](https://github.com/murmur-nexus/murmur/pull/169))
- Breaking: HTTP inference drivers no longer receive the API key. The runtime authenticates calls itself. Drivers without `inference_auth:` fail with `E-RUN-025`. ([#166](https://github.com/murmur-nexus/murmur/pull/166))
- Breaking: `mur watch` and `mur cancel` take a session address like `@1`. Use `--url` for the old form. ([#163](https://github.com/murmur-nexus/murmur/pull/163))
- Breaking: Deploy is now `mur deploy run`. The deployment list moved to `mur deploy ls`. ([#162](https://github.com/murmur-nexus/murmur/pull/162))
- Breaking: Background commands discarded at session end are reported in one grouped summary. `W-SEC-022` warns when a lifecycle can never receive command results. ([#159](https://github.com/murmur-nexus/murmur/pull/159))
- Breaking: Name resolution no longer uses the system resolver. `/etc/hosts` still works, but mDNS and `nsswitch.conf` do not. Pin such names in `/etc/hosts`. ([#152](https://github.com/murmur-nexus/murmur/pull/152))
- Breaking: Runtime scaffolding moved to `.murmur/<session-id>/`. Sealed capsule `/tmp` writes now count toward the workdir size limit. ([#145](https://github.com/murmur-nexus/murmur/pull/145))
- Breaking: The disk IO limit (100 MiB/s default) is now enforced. Raise it if needed. Sealed capsules are refused early on hosts that block `pivot_root`. ([#146](https://github.com/murmur-nexus/murmur/pull/146))
- Breaking: `mur cancel` stops a running task, which ends in a new `canceled` state. Update clients that match on task states. ([#143](https://github.com/murmur-nexus/murmur/pull/143))
- Breaking: `mur-roost` limits live capsules per host. Raise it with `--max-live-capsules`. ([#142](https://github.com/murmur-nexus/murmur/pull/142))
- Breaking: `mur doctor` checks env grants across all spawnable capsules and fails on missing or excess names. ([#139](https://github.com/murmur-nexus/murmur/pull/139))
- Breaking: A delegation that hits its deadline keeps the child running and reports back later. Set the wait with `lifecycle.delegation_deadline_secs` (default 600). ([#131](https://github.com/murmur-nexus/murmur/pull/131))
- Breaking: `mur install` no longer falls back to another platform's release. It fails and lists what is available. ([#126](https://github.com/murmur-nexus/murmur/pull/126))
- Breaking: Native artifacts are stored per platform. Regenerate `murmur.lock` and reinstall native artifacts. ([#123](https://github.com/murmur-nexus/murmur/pull/123))
- Breaking: Tool artifacts built for the wrong platform are refused at startup. `mur doctor` output wording changed. ([#120](https://github.com/murmur-nexus/murmur/pull/120))
- Breaking: `share-file`, `fetch-peer-file` and `delegate-task` are reserved names. Conflicts fail with `E-CAP-013`. ([#121](https://github.com/murmur-nexus/murmur/pull/121))
- Breaking: A plan step's `data_path` must be a real file inside the workdir, or the step fails. ([#113](https://github.com/murmur-nexus/murmur/pull/113))
- Breaking: `mur-roost` limits delegation depth (`--max-depth`, default 3) and live children per parent (`--max-concurrent`, default 4). ([#112](https://github.com/murmur-nexus/murmur/pull/112))
- Breaking: `on-shell` hooks now see the recipe behind `make`, `just` and `npm run`. Rebuild and reinstall all hooks. ([#111](https://github.com/murmur-nexus/murmur/pull/111))
- Breaking: `mur-roost` now only approves spawns. The parent runtime launches the child with `mur run --capsule`. ([#105](https://github.com/murmur-nexus/murmur/pull/105))
- Breaking: Hooks can deny shell commands and tool calls with `commit_policy: deny`. Rebuild and reinstall all hooks. ([#104](https://github.com/murmur-nexus/murmur/pull/104))
- Breaking: Shell commands longer than `lifecycle.shell_grace_secs` (default 10) move to the background. Raise it if you need output in the same turn. ([#102](https://github.com/murmur-nexus/murmur/pull/102))
- Breaking: Untrusted content is wrapped in a delimiter marking it as data. Update prompts and trace parsers. ([#101](https://github.com/murmur-nexus/murmur/pull/101))
- Breaking: User and peer tasks now run before background tasks instead of in arrival order. ([#98](https://github.com/murmur-nexus/murmur/pull/98))
- Breaking: Spawning a child requires a runtime held credential. Capsules can no longer call `mur-roost` directly. ([#99](https://github.com/murmur-nexus/murmur/pull/99))
- Breaking: Child capsules asking for more permissions than their parent are refused with 403. ([#95](https://github.com/murmur-nexus/murmur/pull/95))
- Breaking: `trace.capture` (`none`, `meta` or `content`) replaces `trace.include_tool_output`, which now warns. ([#88](https://github.com/murmur-nexus/murmur/pull/88))
- Breaking: HTTP capsules keep a durable conversation record under `~/.murmur/conversations/`. Threaded conversations now continue across sessions. Old history is not migrated. ([#86](https://github.com/murmur-nexus/murmur/pull/86))
- Breaking: Hooks now use interface version 0.6.0. Rebuild and reinstall all hooks. ([#84](https://github.com/murmur-nexus/murmur/pull/84))
- Breaking: Trace format changed: one session frame per launch, event ids and real task exit status. Update trace tooling. ([#82](https://github.com/murmur-nexus/murmur/pull/82))
- Breaking: `inference.max_task_reopens` is now `lifecycle.max_task_reopens`. ([#69](https://github.com/murmur-nexus/murmur/pull/69))
- `--explain-scope` explains what the filesystem boundary does not restrict and how to test containment properly. ([#149](https://github.com/murmur-nexus/murmur/pull/149))
- `E-CAP-006` now suggests the portable fix first, such as `python3 -m pytest`. ([#147](https://github.com/murmur-nexus/murmur/pull/147))
- All commands that take a session accept the same address formats. With no address they use the latest session. ([#94](https://github.com/murmur-nexus/murmur/pull/94))
